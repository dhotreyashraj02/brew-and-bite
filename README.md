# ☕ Brew & Bite

### Modern Café & Restaurant Website

Brew & Bite is a modern, responsive café and restaurant website designed to provide a clean, attractive and user-friendly digital experience.

The project focuses on responsive web design, modern UI, interactive elements and a visually engaging presentation of café services and menu items.

---

## 🌐 Live Demo

**Visit the live website:**  
https://dhotreyashraj02.github.io/brew-and-bite/

---

## ✨ Features

- ☕ Modern café and restaurant landing page
- 📱 Responsive design for different screen sizes
- 🍽️ Interactive menu section
- 🖼️ Café, food and restaurant gallery
- 📖 About section
- 🎨 Modern and clean user interface
- ⚡ JavaScript-based interactions
- 🌐 Hosted using GitHub Pages

- **HTML5** — Website structure
